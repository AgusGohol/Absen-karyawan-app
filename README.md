# Absensi Karyawan — Aplikasi Android

Aplikasi Android untuk absensi karyawan dengan scan QR.

**Unduh:** https://absensi-karyawan-skena.web.app/app
(atau langsung: [absensi-karyawan.apk versi terbaru](https://github.com/AgusGohol/Absen-karyawan-app/releases/latest/download/absensi-karyawan.apk))

- Android 8 ke atas
- Setelah terpasang, update berikutnya ditawarkan otomatis di dalam aplikasi.
- Tanpa aplikasi (iPhone/laptop): buka https://absensi-karyawan-skena.web.app di browser.

Repository ini hanya berisi file rilis (.apk) di menu **Releases**.
